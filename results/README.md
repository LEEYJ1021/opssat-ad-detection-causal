# `results/` — OPS-SAT-AD Detection & Causal Signature Analysis

This folder mirrors the `results/` layout described in the top-level repository
`README.md`. Every CSV/JSON here is either a directly reproduced pipeline artifact
(Layer 2 detection-stage files, supplied as-is) or a machine-readable transcription
of the exact numbers locked in `docs/dev-log/step1_signal_estimation.md`,
`step2_anomaly_detection.md`, `step3_causal_analysis.md`,
`step3b_labeling_protocol_revalidation.md`, and `step_ai_model_cross_validation.md`.
Figures are regenerated byte-for-byte by the `.py` script sitting next to each `.png`
in `figures/`.

## Notes on scope

- `channel_scope.json` labels ("포함", "구조적 제외 (anomaly=0)", etc.) are kept in their
  original Korean as emitted by the pipeline; `channel_scope_final_locked.csv` carries the
  same decisions. English glosses: 포함 = *included*; 구조적 제외 = *structural exclusion*
  (zero anomalous segments); 표본부족 = *underpowered* (sample-size exclusion); 우연수준 이하
  = *at-or-below chance* (MCC ≤ 0).
- `onset_posteriors.parquet` (the per-segment 200-draw BOCPD Monte Carlo posterior, referenced
  in the top-level README's repository tree) is raw per-draw data, not a summary table, and is
  not reconstructable from the dev-log narrative alone — regenerate it by re-running
  `layer3_causal_analysis/onset_mc_propagation.py` against the locked Layer 1–2 outputs.
- `docs/tables/*.tex` in `tables/` are direct `pandas.DataFrame.to_latex()` exports of the CSVs
  in this folder and are meant as camera-ready drop-ins for the manuscript, not as a separate
  source of truth — if a CSV is corrected, regenerate its `.tex` mirror from it.
