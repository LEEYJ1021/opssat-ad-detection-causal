# `results/` — OPS-SAT-AD Detection & Causal Signature Analysis

This folder mirrors the `results/` layout described in the top-level repository
`README.md`. Every CSV/JSON here is either a directly reproduced pipeline artifact
(Layer 2 detection-stage files, supplied as-is) or a machine-readable transcription
of the exact numbers locked in `docs/dev-log/step1_signal_estimation.md`,
`step2_anomaly_detection.md`, `step3_causal_analysis.md`,
`step3b_labeling_protocol_revalidation.md`, `step_ai_model_cross_validation.md`,
and `step_external_validation.md`.
Figures are regenerated byte-for-byte by the `.py` script sitting next to each `.png`
in `figures/`.

## Notes on scope

- `channel_scope.json` labels ("포함", "구조적 제외 (anomaly=0)", etc.) are kept in their
  original Korean as emitted by the pipeline; `channel_scope_final_locked.csv` carries the
  same decisions. English glosses: 포함 = *included*; 구조적 제외 = *structural exclusion*
  (zero anomalous segments); 표본부족 = *underpowered* (sample-size exclusion); 우연수준 이하
  = *at-or-below chance* (MCC ≤ 0).
- `onset_posteriors.parquet` (the per-segment 200-draw BOCPD Monte Carlo posterior) is raw
  per-draw data, not a summary table, and is not reconstructable from the dev-log narrative
  alone — regenerate it by re-running `layer3_causal_analysis/onset_mc_propagation.py`
  against the locked Layer 1–2 outputs. It is consumed downstream by
  `opssat-ad-risk-optimization` and `opssat-ad-dss`.
- `external_validation/` is the only onset-independent evidence in this repository: SMAP/MSL
  and SMD onsets are ground-truth labels, not BOCPD estimates. `stage1_*` files replicate the
  §3.7 placebo-pool test (Fig. 6); `stage2_*` files replicate the §3.2–3.3(c) temporal-precedence
  test with normal-segment control and the resulting baseline decomposition (Fig. 7).
  `window_cap_sensitivity.csv` documents the 150–5,000-sample sweep confirming that the
  ground-truth-onset, non-sliding, adaptive-window method used in Stage 2 is not censoring-biased.
- Pooled `stage1_placebo_pooled_dataset.csv` p-values treat anomaly windows as exchangeable
  even though they are nested within channels/machines, so they are nominal; the more
  conservative summary is `stage1_channel_level_significance.csv` (SMD channel-level counts,
  Fig. 6b), which shows a ~1.5× gap between derivative and level features rather than the much
  larger pooled-p-value gap.
- `docs/tables/*.tex` in `tables/` are direct `pandas.DataFrame.to_latex()` exports of the CSVs
  in this folder and are meant as camera-ready drop-ins for the manuscript, not as a separate
  source of truth — if a CSV is corrected, regenerate its `.tex` mirror from it.
